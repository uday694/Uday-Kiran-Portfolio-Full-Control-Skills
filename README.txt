UDAY KIRAN DEVASANI — PORTFOLIO

START
1. Extract this ZIP into a folder on your computer.
2. Open Uday-Portfolio/admin.html to manage your portfolio.
3. Use Skills Management to add, edit and delete individual skills and set your current skill level.
4. Use ADD PROJECT to create projects, upload a thumbnail, edit details, and add project links.
5. Use the Resume library section to upload multiple PDF resumes and choose which is the main resume.
6. Click SAVE ALL CHANGES.
7. Open index.html (or use a local web server such as VS Code Live Server) to preview the portfolio.

PROJECTS
- Add unlimited project entries through the dashboard.
- Each project can have a title, full description, tools, URL and image.
- Use EDIT or DELETE beside an existing project.
- Keep each project image under 900 KB.

RESUMES
- Upload multiple PDF versions, e.g. Data Analyst Resume and General Fresher Resume.
- Choose MAKE MAIN to set the primary resume.
- Keep each PDF under 1.2 MB.

STORAGE / BACKUP
This is a browser-based local dashboard. Content is saved in the browser's local storage for the same browser profile and computer. It is not automatically published to the internet and is not shared across devices. Browser storage has limits; use compressed images and PDFs. Export a backup regularly using BACKUP & RESTORE. If browser storage fills up, reduce file sizes or host documents/images online and use their public URLs.

IMPORTANT
Do not clear browser site data unless you have downloaded a backup. This package is a local portfolio, not a hosted CMS. For public online publishing and secure multi-device editing, it needs hosting plus a backend or CMS.

SKILLS
- Add skills one at a time from the Skills Management section.
- Choose a level such as Beginner, Foundational, Basic, Intermediate, Currently learning or Proficient.
- Use EDIT or DELETE beside any skill.
- Save all changes; skills are displayed automatically on the public portfolio.
